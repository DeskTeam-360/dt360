ROOT CAUSE
----------
Next.js App Router merges metadata such that a page-level `openGraph` object
replaces the root layout `openGraph`, but if the page does not also set
`twitter`, the layout twitter block is kept. Root layout twitter used the
homepage title/description, so inner pages kept correct og:title/description
(after earlier OG work) while twitter:title and twitter:description stayed on
the homepage copy. og:image also fell back to /opengraph-image for posts/case
studies because featured media was never passed into openGraph.images.

FILES CHANGED
-------------
- lib/seo.ts — withPageCanonical always emits page-specific openGraph + twitter
  (title, description, absolute image URLs, type website|article, absolute og:url)
- lib/blog-single-page.ts — featured image → openGraph.images (article)
- app/case-studies/[slug]/page.tsx — featured image → openGraph.images (article)
- app/layout.tsx — default share image URLs made absolute HTTPS
